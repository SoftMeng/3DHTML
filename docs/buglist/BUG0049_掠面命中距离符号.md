# BUG0049 视线区间判定：射线只擦到一层表面时，距离写成 −(tp−t0) 在 tp<t0 时恒为正

- 状态：已修 · 2026-11-25
- 现象：个别链采样点报出 5~12cm 的「深穿透」，位置却在躯干表面外几厘米 —— 量级远大于画面可见的穿模。
- 根因：`bodyIntervalDepth` 里射线**只命中一层表面**（掠过网格边缘/开口）时按体外处理，距离写 `-(tp - t0)`。当采样点比命中点更近相机（tp < t0）时这个值是**正**的 → 「擦过表面」被读成「深入体内」。符号约定（体外 = 负）只在 tp > t0 时成立。
- 修法：体外距离一律取**到最近表面的带符号距离** `−|tp − t0|`（体内才取正），与内外判定解耦。
- 教训：区间判定的每个分支（两层命中/一层命中/在区间前/后）都要单独验符号 —— E19 的自检点只覆盖了「体内/体外」，没覆盖「掠过」这一支。

- 回归：E18 的网格真值从 124mm 降到 62mm（剩余为真穿透）；E19 自检通过
