# BUG0052 弯折面用绝对提示点：穿模推出把弦转过去后，沿弦分量泄漏到垂直方向 → 肘翻到弦的另一侧

- 状态：已修 · 2026-11-25
- 现象：E7（弯折侧向反关节）在 5 个时刻违例 0.11~0.18m；诊断显示**推出前的弯折侧向是对的**（off0=−0.18），沿视线推出也保得住（offPush=−0.20），坏在**之后**的让位一步（offTilt=+0.16）。
- 根因（两层，同一个错）：
  1. 2 骨 IK 的弯折面由「肘提示点（绝对世界坐标）+ 弦」决定。源视频里手臂折叠得很紧（弦只有 7~15cm），沿视线推 3~8cm 就能把弦转 60°+ —— 提示点里**沿弦的分量**（肘投影到弦的足距 ~0.21m）在弦转动时泄漏到垂直方向，肘于是被放到弦的另一侧。
  2. 「让位」（绕弦旋转肘以避让躯干）同样用绝对提示点做基准面 —— 弦已被推转过，基准面本身就是错的；而让位的候选角里**朝相机转**的方向天然把肘从弦后翻到弦前。
- 修法（弯折面随弦搬运 + 侧向优先）：
  1. `transportedPole`：只搬运「肘相对弦的偏置方向」—— 用最小旋转把弦方向对齐后刚体搬运偏置方向（保持与弦的夹角）⇒ 推出前后肘永远同侧；
  2. 推出**双向都试**（沿视线朝相机/背相机）：深度符号本不可观测（手可能在躯干前也可能在躯干后），取真的让穿透变小的那个；
  3. 推出会翻侧向的候选直接放弃（搬运是刚体的，弦转过 90°+ 侧向仍会翻 —— 宁可留一点穿透也不画反关节）；
  4. 让位改用**当前面**做基准，且同侧候选优先：只有同侧都压不住、穿透超过 E18 的验收阈值（20mm）时才允许翻面 —— 解剖错误 vs 几厘米可见穿透，代价不在一个量级。
- 教训：凡「位置提示点 + 弦」型 IK，提示点被弦的旋转污染是结构性的 —— 要么搬运方向（本修法），要么每次重解后重算提示点。绝对坐标只在不改弦的场合才安全。

- 回归：E7 违例 5 → 0（阈值未动：弯折 15mm/伸直 30mm）；E18 网格真值 0.0mm、运行时采样 15mm（阈值 20mm）
