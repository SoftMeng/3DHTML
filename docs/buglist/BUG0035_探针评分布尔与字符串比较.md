# BUG0035 探针评分把布尔真值与字符串作答直接比较 → 抬手类准确率恒为 0

- 现象：`handUpImgL/ImgR` 准确率 0.0，但逐条记录显示模型答的是对的（如真值 `True`、模型答 `"yes"`）。
- 根因：真值是 Python 布尔，作答是字符串，`a == t` 恒为 False。
- 修法：评分前把布尔真值归一化成 `"yes"/"no"`（`_yn`）。
- 影响：只影响基线测量数字，不影响生产代码；但会让「模型能力边界」的结论完全失真（把可用能力误判为不可用）。

- 回归：`tools/probe_vlm.py` 重新测量，`tools/vlm_baseline.json` 的 `scoreFull/scoreCrop`
