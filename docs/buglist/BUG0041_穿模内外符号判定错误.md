# BUG0041 穿模内外判定用三角形叉积定符号，而 Mixamo 躯干三角形法向朝内 → 全部误判成"在体内"

- 现象：网格级穿模测量报出 10~12cm 的穿透，位置却在**躯干身后 17cm**（明显在体外）；视觉上人偶并无穿模。
- 根因：符号判定取最近三角形的叉积法向。Mixamo 导出的躯干三角形法向朝内 → 「点在表面后方」被判成「在体内」；法向朝外的头部三角面则判对 → 同一模型不同部位符号相反。
- 试过并放弃的方案：
  - 奇偶判定（射线与三角面相交次数）：网格非封闭（模型有开口），奇偶不成立，误判更大；
  - 径向判据：星形假设对躯干成立，但射线首次命中的距离在部分方向上取到远处三角形。
- 最终修法：**符号由保守代理给（OBB/椭圆包络 ⊇ 网格），量级由网格表面距离给** —— 代理是保守的，落在代理外一定在网格外；落在代理内则按到网格表面的距离计深。同时把网格距离改为「到最近三角面的距离」（原来用的是沿法向的深度）。
- 判据本身的教训：**穿模量必须先定义清楚**（深度沿哪个方向量、符号由谁给），否则测的是"看起来像穿模"的量。

- 回归：`__app.penetration(t)` 的 `env`（顶点相对保守包络的深度）在本轮实测最大 9.5cm，与截图里手插进髋部一致
