# BUG0045 穿模判据把身体各部位合成一个实体 → 两腿之间的空隙被判成"在体内"

- 状态：已修 · 2026-11-25

- 现象：手在髋部外侧（画面上明明在身体旁边）被判 9cm 穿透；点在两腿之间也被判为体内。
- 根因：视线穿透区间把躯干、头、左腿、右腿的三角面合起来算一个 `[前表面, 后表面]` 区间。射线穿过两腿之间的空隙时，前表面取到左腿的前沿、后表面取到右腿的后沿 —— 中间的空隙就被算成实体内部。
- 修法：**每个部位各自是一个实体**，逐部位算区间；点在任一部位内即在体内（量级取各部位的最小值），都不在才算体外（取到最近表面的距离）。

- 回归：E19 的四个体外点（上方/身后/身前/侧方）全部量出 ≤0；E18 逐顶点最深从 128mm 降到 62mm
- 教训：物理上分离的部件（两条腿）不能用一条射线区间合并 —— 合并的是"射线穿过的所有表面"，不是"一个实体"。
