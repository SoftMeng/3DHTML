# BUG0047 姿态保真拿二维膝角当参照 → 把真实深度当成误差

- 状态：已修 · 2026-11-25

- 现象：E3 膝角平均偏差 22.3°（阈值 22°，FAIL），逐样本偏差 0.4°~94.6°。
- 根因：三维膝角与**二维**膝角直接比。但画面里的大腿投影只有解剖长的 66~91% ⇒ 腿明显是透视缩短的（出平面 20~50°），此时三维膝角本就应该与画面夹角不同 —— 那是重构出来的真实深度，不是误差。
- 修法：参照量换成**动作文件三维骨架**的膝角（渲染器要对得上文件），二维膝角降级为参考列。实测：投影长/解剖长 = cos(出平面倾角)，倾角 > 22° 的样本不参与 3D-2D 直接比较。

- 回归：E3 膝角平均偏差 12.4°（n=12，阈值 22°）；深度侧的一致性由 A5 独立把关（3D-2D 夹角差中位 1.0°）
- 教训：拿 2D 量当 3D 的参照前，先问「这个 2D 量是不是无偏估计」—— 透视缩短下它有系统性偏差。
