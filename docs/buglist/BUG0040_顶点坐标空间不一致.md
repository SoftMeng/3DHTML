# BUG0040 getVertexPosition 返回网格局部坐标，与骨的世界坐标不同空间 → 代理半径算成米级

- 现象：代理半径出现 5~8 米的量级，穿模推出把手甩到画面外。
- 根因：`SkinnedMesh.getVertexPosition()` 返回的是**网格局部坐标**（蒙皮矩阵 bindMatrix/bindMatrixInverse 把场景空间抵消掉了），而骨的世界位置在场景空间 → 两者相差模型的节点缩放与位移。
- 修法：顶点位置量测后统一 `applyMatrix4(mesh.matrixWorld)`，与骨的世界坐标同空间。
- 同源问题：网格级穿透测量若不刷新世界矩阵，量到的是**上一帧**的顶点（`updateScene` 只改骨骼姿态，不刷新矩阵）→ 必须在测量前 `figGroup.updateMatrixWorld(true)`。

- 回归：探针 `__app.proxyInfo()` 的 `radii` 全部在 0.03~0.16m 区间
