# BUG0050 穿透量按「中心深度 − 采样半径」计 —— 手心藏在袖筒里的负值把指尖的真穿透抵消掉

- 状态：已修 · 2026-11-25
- 现象：指尖明明插进躯干（画面可见），链采样真值却量出 0。
- 根因：表面穿透写成 `d − r`（中心在体内的深度减采样半径）。判据的采样点里有**手心**（藏在袖筒/掌背不可见）和**指尖**（裸露、可见）两种：手心在袖筒里时中心深度为负，`d − r` 后是大的负值；指尖是正的小值 —— 求和/取最值时**负的把正的吃掉了**。
- 修法：表面穿透 = `d + r`（朝身体方向的偏移是**更深**），并把判据限定在**可见的手部几何**（裸露的手指）：掌背在卫衣里、袖筒与躯干是同一件衣服，本来就不构成可见穿模。
- 教训：带符号的量做聚合前，先问每一项的符号语义是不是同一件事 —— 「藏在衣服里」和「穿出身体」在该判据下方向相反，混在一起就是互相抵消。

- 回归：E18 手指网格真值从 25mm 降到 0.0mm（11 个时刻全部 ≤ 阈值）
