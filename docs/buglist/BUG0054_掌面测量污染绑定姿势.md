# BUG0054 掌面测量播放模型动画只还原四元数 → 绑定姿势被污染 → 人偶脚陷进地面 22cm

- 现象：E13 实测渲染占比 58.2% → 68.2%（人偶高 17%）；E3 膝夹角偏差 19.8° → 26.9°；E7 出现弯折侧向违例。同时截图里**鞋底陷在舞台地面以下 22cm**。
- 根因：`measurePalmAxes` 为了实测掌面法线，播放了模型自带动画（Mixamo 的根骨带**位置轨道**），测量结束后只还原了骨骼的 `quaternion`，**没还原 `position`/`scale`** → 出厂绑定姿势被静默改写 → 腿长被改 → 髋位下移 24cm、腿被拉直 → 脚陷地。
- 定位手段：用 `history/R15_round1/index.html` 做 A/B（同一套验收脚本）→ R15 版本 E3/E7/E13 全绿，一换成本轮代码就全红 → 确认是本轮引入 ✓。
- 修法：测量前保存并还原骨骼的**位置/旋转/缩放**三项。
- 教训：任何"临时播放动画做测量"的代码都必须完整还原状态，否则会污染生产路径（且症状出现在别的断言上）。

- 回归：`tools/verify.mjs` → E3/E7/E13 全绿；E13 实测渲染占比 58.2%（偏差 1.0%）
