# BUG0044 射线-三角形求交符号写反（u 与 t 取反）→ 所有命中被判非法 → 穿模判据恒为 0

- 状态：已修 · 2026-11-25

- 现象：网格级穿模量恒为 0（11 个时刻全是 0mm），而画面上手指明显插进躯干；E19 自检里"胸口在体内"也量成 0。
- 根因：`rayNearestHit` 的 Möller–Trumbore 展开式中重心坐标 `u` 与射线参数 `t` 的符号与标准写法相反 —— 合法命中的 `u` 算成 −u ∈ [−1,0]，被 `if(u<0||u>1) continue;` 全部判成非法。**求交永远不命中，穿模判据永远返回 0**，而且不报任何错。
- 修法：改用向量积显式表达的标准写法（`pvec = D×e2`、`qvec = tvec×e1`），并加自检 —— 已知点在体内必须量出正深度（E19：胸口 42mm），四个已知在体外的点必须量出 ≤0（上方 3m / 身后 30cm / 身前 30cm / 侧方 35cm）。
- 连带删掉：旧的 `meshDepth` / `groupDepth` / `rayNearestHit`（判据已由视线穿透区间取代）。

- 回归：E18 的网格真值从"恒 0"变成真实值（最深 62mm，链采样点 25mm）；E19 通过
- 教训：**判据本身要被判据检验** —— 没有自检的度量，出错时只会安静地给出好看的数（0 恒 ≤ 阈值）。
