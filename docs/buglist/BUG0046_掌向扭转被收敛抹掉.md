# BUG0046 掌向扭转在穿模收敛之前做 → 被收敛重解手臂链抹掉

- 状态：已修 · 2026-11-25

- 现象：掌向机制残差在部分帧高达 65.6°（阈值 25°），而且是**时好时坏** —— 穿模收敛触发的帧就丢扭转。
- 根因：扭转写手骨的四元数，而穿模收敛里的 `solveChain` 会**重写**手骨四元数 —— 收敛在扭转之后跑，扭转被抹掉。
- 修法：收敛**前**先扭一次（手指朝向决定指尖会不会插进身体，不先扭好穿模判据量的是没扭的手），收敛重解链之后再补一次。扭转是幂等的（按当前法线与目标的夹角做增量旋转），补扭不会转两次。

- 回归：E17 机制残差最大 0.1°（阈值 25°）
