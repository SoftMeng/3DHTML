# BUG0039 袖筒半径换算漏了 Mixamo 的单位因子 → 代理半径 6.7 米 → 手被推出 8 米

- 现象：IK 末端偏差 8.26 米（正常 < 0.25），手的动作目标跑到相机身后 5.3 米。
- 根因：袖筒半径写在**骨骼局部单位**里（Mixamo 骨长单位 = 1cm，模型根节点带 0.01 缩放）。换算到世界应为 `骨的世界缩放 × 半径`（= 0.01 × wrapper 缩放），代码却只乘了 wrapper 的缩放 → 6.2 变成 **6.76 米** → 穿模推出按"穿透深度"推 6.7 米。
- 修法：用**骨的世界缩放**换算（`bone.getWorldScale().x`），并加半径合理性闸门（人体任何部位 < 0.5m，超出即丢弃该代理）。
- 附带：推出量上限 30cm，代理不可信时宁可不推。

- 回归：探针 `ik` 的手部偏差为 0（命中目标）；E2 通过
