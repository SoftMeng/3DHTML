# BUG0042 深度限速的骨长钳位用了泄漏变量 L → 所有骨的深度幅度被钳到 11cm（眼骨长）

- 状态：已修 · 2026-11-25

- 现象：重建出来的骨长只有解剖长的 75~90%（上臂 0.75、前臂 0.81），手臂在深度方向伸不开 —— 手到不了躯干前面，必然穿模。
- 根因：`depth_reconstruct.py` 的限速循环里写 `if(abs(v) > L) v = ±L`，但这个循环**没有自己的 `L`** —— 用的是上面 Viterbi 循环残留的变量，值是最后处理的那根骨（`right_eye`）的解剖长 0.112m。于是每根骨的 |Δz| 都被钳到 11cm：上臂的透视缩短解出 24.6cm，被砍到 11.2cm。
- 修法：限速循环里按自己的 `seg[segk]` 取骨长；顺带把重累积后的二次限速删掉（见 BUG0043）。
- 影响：修完骨长比回到 0.93~1.07（解剖正确）；A1 深度幅度 0.720 → 0.995；A5 三维-二维夹角差 17.1°（FAIL）→ 1.0°。

- 回归：`tools/verify_depth.py` A1~A5 全过；实测重建骨长/解剖长中位 0.93~1.07
- 教训：Python 里跨函数/跨循环复用的变量名，最容易出这种"值恰好来自别处"的错 —— 限速类钳位必须用**本骨**的常量。
