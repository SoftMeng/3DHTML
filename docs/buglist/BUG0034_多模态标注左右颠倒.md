# BUG0034 多模态标注按「图像左右」提问 → 模型按主体左右作答，左右全反

- 现象：能力基线探针里 `elbowImgL/elbowImgR` 准确率 1/3，且错误**恰好左右互换**（真值 bent/straight，模型答 straight/bent）。
- 根因：提示词要求「图像左/右」，模型仍按**主体自身左右**理解并作答；视频未镜像（人正面朝镜头，主体左手出现在画面右侧），两者恰好相反 → 系统性全反。
- 修法：提问统一改用「person's own left/right」（主体自身左右），与 Schema 语义一致，且对镜像视频天然正确；真值侧同步改用 MediaPipe 的主体相对关键点。
- 影响：掌向/抬手类标注若用图像左右，全帧标签反向 → 掌向会左右互换。已改。

- 回归：`tools/probe_vlm.py` 的逐题准确率（`tools/vlm_baseline.json`）
