# BUG0048 交叉校验的「哪只手更高」不可用：两手常等高 + 左右约定不一致 + 暗色渲染读不准

- 状态：已修 · 2026-11-25

- 现象：轨迹一致性交叉校验里 `handHigher` 的一致率在 0.0 / 0.5 之间跳，只改提示词就翻面 —— 量的是模型的约定与噪声，不是轨迹一致性。
- 三个叠加原因：
  1. **题面本身不可判**：实测 t=2.5 两腕的屏幕高度只差 0.7% 画面高（等高），"哪只更高"没有唯一答案。
  2. **左右约定不一致**：模型对**照片**按人物自身左右回答，对**3D 渲染**按画面左右回答 ⇒ 问"人物自己的哪只手"时两侧天然对不上（一致率 0.0）。
  3. **暗色渲染读不准**：3D 人偶是深色剪影，模型判断哪侧手臂更高本就不稳。
- 修法：换成**身体倾斜方向**（视频与渲染里都显著，且左右镜像会直接翻转答案）；同时只比较**两侧都有信息**的题（视频里 `not_visible`/`unknown` 的题，视频根本没约束，不该算不一致）；提示词去掉与题面矛盾的"按人物自身左右"；缓存键带上提示词指纹（改了题面旧答案不能复用）。
- 复核：原题面（问画面左右）一致率 0.5，改提示词后 0.0 —— 同一帧、同一渲染，只因措辞不同就翻面，确认是噪声不是信号。

- 回归：新题面（身体倾斜）一致率 0.75；总体一致率 0.667 → **0.867**；肘弯曲 0.33 → **0.75**
