# Quality

## 门控

| 层 | 命令 | 何时 |
|---|---|---|
| 构建 | `tools/.venv/bin/python tools/build_page.py` | 改 `src/` 后（index.html 是产物） |
| 内核单测 | `node tools/test_core.mjs` | 改 `src/core/` 后（秒级，不开浏览器） |
| 语法 | `node --check`（改产物后） | 每次改渲染层 |
| 离线断言 | `tools/.venv/bin/python tools/verify_depth.py` | 改深度重构/动作文件后 |
| 视觉探针 | `node tools/probe_render.mjs --view=overlay --times=...` | 每轮迭代一次 |
| 有界验收 | `node tools/verify.mjs` | 每轮迭代一次（最后一道） |

浏览器验收每轮**仅一次**；探针与验收分离，探针不计入验收次数但也不得连跑。

| E | 模型与骨骼映射、IK 命中精度、姿态保真、平滑、时间连续性、弯折侧向解剖、躯干转身、接触门控、人偶比例、动作文件语义、对照机位取景、手部逐点对齐、**脚部逐点对齐(E16)**、**掌向(E17)**、**无穿模(E18)**、**穿模判据自洽(E19)** |

## 规则

- 断言要量**渲染结果**，不能量解析式。
- **判据本身要被判据检验**：度量出错时不会报错，只会安静地给出好看的数。穿模判据配一条自检断言（已知体内点必须量出正深度、已知体外点必须量出 ≤0），否则「恒为 0」会被当成「没有穿模」。
- **失败先量后修**：断言挂了先加诊断（哪一步翻的、量是多少），按量到的根因修；不允许把阈值放宽到刚好盖住残差 —— 阈值是判据，残差是事实，改判据要有独立理由（参照量不可观测、判据在某个区间失效）。
- 启动类行为必须查 `ready` + 错误面板。
- 阈值必须来自**实测分布**（先量再定），不允许拍脑袋。
- 修 bug 必须补回归断言；验收盲区类缺陷要单独标记。
- 未跑门禁不得声称完成；禁止为通过检查删断言或放阈值。
- **重构要证明等价**：拆分后 app 段与原文件归一化逐行零差异；内核接线后由 48 条断言的**数值**逐项比对（不只是 PASS/FAIL）。
- **运行时的量与验收的量同源**：收敛用的判据和断言里的判据量的是同一个量（如弯折侧向 = `chainBendOff` 与 E7 的 `bendSide` 同量纲），否则收敛"修好了"验收仍会挂。

## 禁止

- 大范围无关修改混入功能提交。
- 把「当前做不到」写成断言通过（应记为已规避 + 写清绕开方式）。
