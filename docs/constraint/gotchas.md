# Gotchas

项目特有的坑。**动这块代码前先读。**

## 坐标系与符号

- 规格 x 入料必须取负：相机首帧朝 +Z，此时屏幕右 = 世界 −X，不取负就是水平镜像（对称规格看不出来）。
- `yawOf(f) = atan2(−cos f, sin f)`；用 `atan2(−cos,−sin)` 会差 180°，facing 270 变成背对镜头。
- `poses` 是**图像系**（x=画面右），只做了减髋中点/除躯干长/翻 y，**不按偏航旋转**。可直接当相机系切向坐标用。
- MediaPipe Hands 的 `handedness` 在非镜像输入下会翻转 → **不可用于选左右手**，改用与 BlazePose 腕点的距离指派。

## 量纲

- Mixamo 导出 **100 单位 = 1m**；骨骼局部单位 ≠ 米，位移必须除以父级世界缩放。
- 骨骼局部空间与世界空间缩放不同 → IK 全程在世界空间做；旋转增量用 `q_parentWorld⁻¹·δ·q_parentWorld` 折算到父级局部。
- `bone.quaternion.copy(q).multiply(bone.quaternion)` 得到 **q²**（copy 已覆盖原值），必须先 `const old = bone.quaternion.clone()`。
- OpenCV uint8 HSV **色相范围 0–179**；藏青写 215 会回绕成绿色。写入前除以 2，藏青用绝对饱和度。

## 姿态

- 逐帧 `multiply(增量)` 会累积（每帧 −0.013rad → 70 帧后 90°）。用初始姿势作基准的**绝对姿态**：`bone.quaternion = q_delta · initQuat`。
- 绝对姿态赋值在链上会叠加（Spine 依次赋 1/3、2/3、1 → 实际 2 倍）。躯干分段弯曲必须用**链式增量**。
- Mixamo 骨链：`LeftShoulder` 是**锁骨**，上臂是 `LeftArm`。
- 模型脊柱沿 −Z（up=−Z）；按包围盒高度归一化会把 **T-pose 臂展**当成身高。用骨架基摆正：`up=头−髋`、`left=左手−右手`、`fwd=left×up`、R=Basisᵀ。

## 骨架与几何

- GLTFLoader 把 `mixamorig:Hips` 洗成 `mixamorigHips`（分隔符直接消失，不是换成 `_`）→ 用归一化匹配 `name.toLowerCase().replace(/[^a-z0-9]/g,'')`。
- `geometryBox` 对 SkinnedMesh 算**蒙皮后**顶点 → 骨架带着上一规格动画的姿势时包围盒会漂（人偶平移 23cm、比例漂 2%）。**测量前必须还原绑定姿势**（GLB 装载时快照）。
- 身高按**可见剪影**（发顶→鞋底）配平，长发必须在测量前挂上，否则人偶量矮一截。
- Mixamo 65 骨**没有发骨** → 头发只能外挂几何；发髻（x≈±0.2m）必须几何级修剪，发片盖不住。
- wrapper 跨规格复用 → 挂件会累积（draw call 线性增长）。挂件缓存复用。

## 深度与时间

- 透视缩短在 d/L→1 处**病态**：`dz/dd = −d/dz`，2D 袖口/裤脚噪声被放大成 ±15cm 深度摆动 → 离线 5 帧中值去离群（不做低通）+ 运行时 τ=0.10s 低通 + 深度不可信时保持上次可信值。
- 横向骨（肩/髋/耳）的深度由偏航给出 `±L·sin ψ`，**不要从 2D 肩宽反推**（转身期肩宽骤变会把深度算飞）。
- 离线不做低通：任何低通带滞后（One-Euro 0.8Hz 实测滞后 125ms），滞后比噪声更伤一致性。
- 3 帧中值去离群、保阶跃；高斯 ±3 帧会把一帧内的快动作抹平 7 帧。
- 缺失关键点必须写 `null`，不能写 `[0,0,0]`（会被当有效点 → 画面基准把头顶算到画外 → 人偶放大 2 倍）。
- 滤波器（`sm`/`sm1`/`sm3`/`smoothReach`）必须处理时间跳转：硬 seek 后状态属于上一时刻，会量到混合值。
- 头/胸的二阶弹簧在时间跳转时也要直接落目标：不落的话，同一时刻的测量随历史漂移，穿模实测值在两次验收间能差一倍以上。
- **跨循环复用的变量名**是深度重构里最贵的 bug：限速钳位用错泄漏变量 ⇒ 所有骨的深度幅度被钳到另一根骨的长度（骨长只还原 75%）；重累积后的二次限速作用在泄漏键上 ⇒ 只有一只脚被限速。

## 验收

- 断言要量**渲染结果**，不能量解析式（相机反解与 videoBox 同源，比对必然通过）。
- 启动类失败必须查 `ready` + 错误面板；只查 `playhead`/`spec`/`url` 会让「启动失败」照样 PASS。
- E7 类解剖断言要分档：伸直肢体的弦上偏移趋零、由噪声定符号，不能要求符号恒定。
- 胶囊代理偏乐观，最终以蒙皮网格相交为准；代理半径要按**服装剪影**外扩。
- 代理是**包络**：它既会偏大（手在身前仍报穿透），也会偏小（腕部在网格内、代理判在外）⇒ 量级必须以网格为准，代理只当筛子。
- 网格穿模判据：内外判定**不要用三角形法向**（Mixamo 躯干法向朝内，会全判反），也**不要用奇偶**（网格非封闭）；用「相机射线的前后两个交点」定区间。物理上分离的部位（两条腿）要**各自**算区间，合成一个会把腿间空隙判成实体。
- 射线-三角形求交要写成标准 Möller–Trumbore：重心坐标与射线参数的符号弄反时，**所有命中都会被判非法**，度量恒为 0 且不报错。
- 度量要配**自检断言**（已知体内点量出正深度、已知体外点量出 ≤0），否则"恒 0"会被读成"没问题"。
- 穿模收敛要在掌向扭转**之后**：扭转写手骨四元数，收敛里的 `solveChain` 会重写它（顺序反了扭转被抹掉）。
- 沿相机射线推出时，推不出改善就回退：否则一路累加，手会被甩到身前 30cm（画面位置不变，深度全错）。
- **弯折面不能给绝对提示点**：2 骨 IK 的提示点是绝对世界坐标时，弦一旦被（推出）转过去，提示点里沿弦的分量会泄漏到垂直方向，肘翻到弦的另一侧（反关节）。收敛里改用**随弦搬运的极向量**（保「肘相对弦的偏置方向」与弦的夹角）；让位绕弦旋转时同侧候选优先，解剖错误（翻面）只用来换超过验收阈值的可见穿透。
- **深度符号双向试**：手在躯干前还是躯干后，正视图判不了 —— 沿视线两个方向都试，取真的让穿透变小的那个；单方向推会把「手在身后」的构型越推越深。
- **检测器的左右归属是假设不是事实**：MediaPipe 逐帧独立判左右，转身/遮脸时会整段标反（上半身可以单独反）—— 提取管线先做翻转修复（2 态 Viterbi，按帧计代价，短 glitch 修得起、真实转身不误伤）再进深度重构。换检测器档位要先复测：full 档零翻转但深度时域更抖，未必净收益。

## 模型与单位（Mixamo / three.js）

- **骨长单位**：Mixamo 骨长 1 单位 = 1cm（模型根节点 `Character` 带 0.01 缩放）。
  写在外挂几何里的尺寸（如袖筒半径 6.2）要乘**骨的世界缩放**才得到米；只乘 wrapper 的缩放会差 100 倍。
- **骨名被 loader 剥字符**：three.js 的 GLTFLoader 用 `sanitizeNodeName` **删除**冒号 → `mixamorig:LeftHand` 在运行时是 `mixamorigLeftHand`。
  按原名查找必然落空 → 统一用规范化名（小写 + 去非字母数字）查找。
- **`getVertexPosition` 返回网格局部坐标**，不是世界坐标 → 与骨的世界坐标不同空间（差模型的节点缩放与位移），
  量出来的"半径"会是米级。与骨的位置比之前必须 `applyMatrix4(mesh.matrixWorld)`。
- **测完要还原干净**：临时播放模型动画做测量（如实测掌面法线）会改写骨骼的**位置轨道**；
  只还原四元数会静默污染绑定姿势 → 人偶比例错乱（实测脚陷地 22cm，症状落在 E3/E7/E13 上）。
  位置/旋转/缩放三项一并还原。
- **模型自带的三角面绕序可能朝内** → 用叉积法向判"点在体内"会整体判反；
  内外判定改用**保守代理给符号、网格表面距离给量级**。

## 多模态模型

- 提问用**主体自身左右**，不要用「图像左/右」：模型会把「图像左」理解成主体左 → 标签全反（源视频未镜像时恰好相反）。
- 它的能力边界要**实测**：深度序 20~42%、掌向重复提问翻转率 35% → 这两类**不进渲染管线**；
  只做场景/动作/朝向这类语义标注。测量见 `docs/constraint/vlm_boundary.md`。
- 端点偶尔 HTTP 400「Model output became abnormal」（模型生成的 JSON 异常被中止）→ 客户端带重试与缓存。

## 重构与模块化

- **内联产物与源码必须能对上**：签入的 `index.html` 与 `src/` 重建结果逐字节一致（B18 断言），
  否则「改了源码忘了重建」会静默生效。
- **ESM 里导入的绑定不可写**：跨模块改状态必须走接口（setter），否则源码在未打包时直接 TypeError；
  反过来，批量把 `x = v` 改写成 `setX(v)` 时**复合赋值（`x += v`）必须保留读旧值语义**（BUG0053）。
- **批量改写脚本本身要被行为断言覆盖**：改写器出错的症状落在别的断言上（播放头被重置 ⇒ E18 量到别的帧），
  语法检查通过 ≠ 行为正确。
- **模块内联后是同一作用域**：模块间顶层重名会互相覆盖（构建器要查重名）。
- **几何内核要零依赖**：不碰 DOM / three.js / 全局状态，才能在 Node 里秒级单测；
  纯函数 + 不变量断言比浏览器端到端快三个数量级。

## 浏览器

- 单实例；每轮迭代最多跑 1 次验收；结束必 kill + `ps` 自查。
- `.then(()=>process.exit(0))` 会**跳过 `.finally`** → 清理不执行 → 残留 Chrome 烧用户 CPU。用 `process.exitCode` + 在 `finally` 内退出。
- 无头 Chrome 下 `Page.captureScreenshot` 得黑图 → 用 `canvas.toDataURL()`。
- Node22 的 `fetch` 收大响应偶发 raw-throw → 一律用 `node:http` 做探针。
