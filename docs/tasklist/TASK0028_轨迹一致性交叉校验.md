# TASK0028 轨迹一致性交叉校验器（难点四：准确性校验的独立证据链）

- 状态：已完成 · 2026-11-25
- 产出：`tools/verify_vlm.py` · `tools/vlm_consistency.json` · `tools/vlm_verify_cache.json`

1. **做法**：同一个多模态模型，分别看**源视频帧**与**3D 渲染帧**（对照机位，人偶与视频同尺寸同位置），回答同一组问题；两次回答的一致率 = 轨迹与视频的一致性得分。
2. **不依赖本项目的解析式，也不依赖渲染层自报的量** —— 是一条独立证据链；渲染层的断言量的是自己算的东西，交叉校验量的是"看起来像不像"。
3. **实测结果**（4 个时刻，12 个可比对）：总体一致率 **0.67**；逐题 —— 哪只手更高 100%、人朝哪 100%、肘是否弯曲 33%、掌朝哪 33%。
4. **它直接指出了下一轮该修什么**：肘弯曲的一致率最低（视频里"两只都弯"、渲染里"一只弯"）→ 手臂的肘部姿态与视频仍有系统性差异；掌朝哪 33% 与"掌面在宽袖里本就不可见"一致（不是渲染的错）。
5. **定位与用法**：作为**相对指标**（比较不同版本），不进发布门槛 —— 模型自身有噪声（翻转率 35%），绝对值不可信。端点偶尔返回 HTTP 400（模型生成 JSON 异常被中止），客户端已带重试与缓存。

- 验收：`tools/verify_vlm.py --tag=<探针标签> --times=...` → `tools/vlm_consistency.json` 输出一致率与逐题分解
