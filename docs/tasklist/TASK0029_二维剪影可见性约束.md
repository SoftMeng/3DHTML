# TASK0029 深度序的第二条证据：2D 剪影可见性约束

- 状态：已完成 · 2026-11-25
- 产出：`tools/depth_reconstruct.py`

1. 问题：单目深度重构的符号歧义（骨在视线前方还是后方）原先只靠**解剖先验**（肘偏后/膝偏前）+ 帧间连续性裁决。先验说"肘偏后"，视频里手却画在躯干**之前** —— 于是整只手被放到身后，3D 里手整只消失进身体（穿模）。
2. 依据：肢体末端画在躯干剪影**内** ⇒ 它在躯干前方（被躯干挡住就看不见了）。这是 2D 真正能给出的深度序线索。
3. 实现：逐帧算躯干四边形（肩+髋，内缩 12%）与左右大腿带（髋→膝，半宽 0.085 躯干长）；末端关键点落在这两个剪影内时，给「它在躯干前方」的线性惩罚 `W_VIS·max(0, z − vis_front)`（每米 60，10cm 的违反 ≈ 6，压过解剖先验 0.8）。实测触发 811 次。
4. 效果：先验满足率 98% → **100%**；肘/腕的符号翻转次数 2 → 0。

- 踩过的坑：剪影内缩比例不能减小 —— 实测 0.04 会把「手在体侧」误判成「画在躯干上」，深度序反而更乱（肘的符号翻转 0→2、A4 先验满足率 100%→84%、t=5 穿透 7cm→44cm）。
- 验收：`tools/verify_depth.py` 的 A1~A5 全过（A4 先验满足率 100%、A5 3D-2D 夹角差中位 1.0°）
