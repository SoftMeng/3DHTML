# TASK0030 穿模判据换成「视线穿透区间」，运行时按真值收敛

- 状态：已完成 · 2026-11-25
- 产出：`index.html`（`rayTri` / `bodyIntervalDepth` / `bodyTopology` / `bodyWorldNow` / `chainTruthPen`）、`tools/verify.mjs`（E18 重写、E19 新增）

1. 问题：原先的穿模量由**保守代理**（躯干 OBB 剖面 + 胶囊）给出。代理是包络，比实体大 → 手明明在身前（视频里手画在躯干之前），代理仍报 3~6cm「穿透」；反过来代理也可能偏小，漏掉真正插进身体的腕部。**量的是代理，不是事实。**
2. 判据换成**网格真值**：相机在体外 ⇒ 沿视线方向第一个交点是前表面、最后一个是后表面，点落在两者之间即在体内，量级取到较近表面的距离。
   - 内外判定**不依赖三角形法向**（Mixamo 躯干三角形法向朝内，用法向定符号会全判反 —— 见 BUG0041），也不依赖奇偶判定（网格非封闭）。
   - 每个部位各自是一个实体（两腿之间的空隙不属于任何一个部位，见 BUG0045）。
3. 运行时收敛：先「弯折面让位」（肘在弦平面内的方位不可观测 → 零代价），再「沿相机射线推出」（针孔投影下射线上的点投影相同 → 画面位置零变化）。推出必须**真的让穿透变小**，否则回退（否则会一路推到底，把手甩到身前 30cm）。
4. 性能：身体网格的拓扑（哪些三角形属于身体）是静态的，只算一次；逐帧只刷新身体用到的顶点（12796 个，约 1.6ms），射线按部位包围盒粗筛（腿部位占 2 万面，不筛每点 0.24ms → 0.002ms）。
5. 掌向扭转时机：手指朝向决定指尖会不会插进身体 ⇒ 扭转必须在收敛**之前**做一次，收敛重解链之后再补一次（扭转是幂等的：按当前法线与目标的夹角做增量旋转）。

- 验收：E18（网格真值 + 代理安全网 + 逐顶点）、E19（判据自洽：胸口判内 42mm，上方 3m / 身后 30cm / 身前 30cm / 侧方 35cm 四个点判外）
