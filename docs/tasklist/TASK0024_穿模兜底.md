- 状态：已完成 · 2026-11-25
- 产出：`index.html`（`PROXY_BONE_MAP` / `measureProxyRadii` / `bodyCapsules` / `pushOutHand` / `resolveChainCollision` / `meshPenetration` / `__app.penetration`）

1. **代理半径由网格实测**：蒙皮网格顶点按主骨骼权重分组，取到骨轴垂距的 95 分位（95 而非 90：代理必须包住网格，否则穿模漏判）。袖筒是外挂几何，用建筒时的已知半径 × 模型缩放。
2. **推出方向 = 相机射线**：针孔投影下射线上的点投影相同，沿射线平移**不改变画面位置** → 穿模修复对视频一致性零代价。相机射线由规格 + 视频基准解算（`videoCamState`），与当前渲染视图无关（换镜头不改动作）。
3. **肘/膝方位不可观测 → 零代价让位**：前臂/小腿穿躯干时绕弦轴旋转弯折面法向（±35° 以内），取穿透最小的一侧（`resolveChainCollision`）。
4. **判据量真实网格**（铁律3）：`meshPenetration` 用手/袖筒的顶点 vs 躯干网格真实三角面的**有符号距离**；两级筛选（胶囊代理筛嫌疑顶点 → 精确三角面距离），全量精确判定太慢。
5. 动作不变式：推出只改深度方向的位移，画面位置逐点不变。

- 验收：`tools/verify.mjs` 断言 **E18**（最深穿透 ≤ 5mm，超限帧 0）
