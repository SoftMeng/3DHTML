1. 问题（实测）：渲染层是 4392 行单模块 + ~30 个模块级可变全局 + 356 处全局读写 + `rig` 24 字段 god-object；
   最该被测的几何（射线求交 / 视线区间 / 2 骨 IK / 弯折面搬运）**只能在浏览器里测** ⇒ 每轮反馈 ≥70 秒。
2. 交付形态不变：`index.html` 仍是**单文件**（`file://` 直开零 CORS，见 B1b），运行零构建。
   源码按职责分模块，由 `tools/build_page.py`（~80 行自研，不引 npm/打包器）内联成产物。
3. 模块与接口：
   - `src/core/`：**零依赖**（无 DOM / 无 three.js / 无全局状态）—— `vec`（Vec3/Quat）、`geom`（rayTri/rayHitsBox/intervalDepth）、
     `ik`（solveTwoBone/transportPole/bendOffset）、`clip`（truthPen）。Node 可直接 import ⇒ **秒级单测**。
   - `src/app/`：`state`（运行时状态 + 跨模块 setter）、`scene`（布景/画质档位）、`figure`（人偶与骨骼）、
     `solver`（模仿驱动/IK/穿模收敛）、`shell`（相机/UI/播放/启动/调试钩子）。`main.js` = 常量 + three.js 载入 + 边界转换。
   - 内核 ↔ three.js 的转换只在 `main.js` 一处（`toVec`/`toThree`）⇒ 耦合点唯一。
4. 行为等价证明：拆分是**机械切分**（原文件按段落切成连续块）⇒ 归一化后 app 段与原文件**逐行零差异**（4325 行）；
   内核接线与 setter 化之后由 48 条断言与逐项数值比对兜底（E14/E16/E19 数值完全一致，E3 12.4°→12.6° 为内核浮点差异）。
5. 状态边界（本轮只定边界，不做全局归编）：跨模块写的绑定由 `state` 提供 setter（38 个 `setStateXxx`），
   ESM 里导入的绑定不可写 ⇒ 写必须走接口；`rig` 仍是一个对象（拆分留待下一轮）。
6. 防漂移：`tools/build_page.py --check` 校验「重建产物 == 签入产物」，并作为验收断言 **B18** 进 `verify.mjs`。
7. 内核单测（`node tools/test_core.mjs`，9 条全过）：射线求交命中/退化/出界/平行；视线区间体内外 + **沿视线符号连续**
   （抓 BUG0053 类符号错）；2 骨 IK 骨长守恒/极向量定侧/越界夹取；**弯折面刚体搬运**（构型整体旋转、侧向不翻，抓 BUG0052）；
   弯折侧向符号；可见手部穿透含半径。
