# TASK0022 多模态大模型客户端与能力基线测量（难点一：边界必须实测）

- 状态：已完成 · 2026-11-25
- 产出：`tools/vlm.py` · `tools/probe_vlm.py` · `tools/vlm_baseline.json` · `docs/constraint/vlm_boundary.md`

1. **客户端**（`tools/vlm.py`）：凭据只从环境变量 `MY_OPENAI_PROXY_URL` / `MY_OPENAI_API_KEY` / `MY_OPENAI_MODEL_NAME` 读取，不落盘、不进日志；HTTP 错误带状态码与响应片段；JSON 模式 + 缺键重问。
2. **基线测量**（`tools/probe_vlm.py`）：9 题问题电池，每题都有**独立真值**（MediaPipe 2D 关键点、本项目的 yaw/pose3d），测三种变体：整帧 / 主体裁剪 / 重复提问（噪声地板）。抽帧按真值位掩码分桶，保证抽到有区分度的帧。
3. **提问用「主体自身左右」**：模型对「图像左右」会按主体左右理解 → 标签全反（见 BUG0034）。
4. **实测结论**（`docs/constraint/vlm_boundary.md`）：模型擅长粗粒度空间关系与动作语义（抬臂 80~90%、朝向 91~100%）；**不擅长深度序（20~42%）与掌向（重复提问翻转率 35%）**。
5. 由此定角色：多模态模型在本管线里是**语义标注器**，不是几何测量器 —— 深度重构不依赖它，掌向不依赖它。

- 验收：`tools/probe_vlm.py --n 12 --repeat` 产出基线 JSON 与报告；逐题准确率与翻转率有数字
