# TASK0034 穿模收敛保弯折侧向（解剖正确优先于可见穿透）

- 状态：已完成 · 2026-11-25
- 产出：`index.html`（`transportedPole` / `chainBendOff` / 双向推出 / 让位同侧优先 / `__app.pushDiag`）、`tools/verify.mjs`（E7 带逐阶段诊断）

1. 问题：穿模兜底的收敛（推出 + 让位）把肘翻到弦的另一侧 → E7 反关节违例 5 处（0.11~0.18m）。根因是绝对提示点在弦转动后泄漏（BUG0052）。
2. 弯折面**随弦搬运**：`transportedPole` 只搬运「肘相对弦的偏置方向」（最小旋转对齐弦方向后刚体搬运，保持与弦的夹角）—— 推出前后肘永远同侧。
3. 推出**双向**：深度符号本不可观测（手在躯干前/后都解释得通同一画面）⇒ 沿视线朝相机、背相机各试一次，取真的让穿透变小的那个；会翻侧向的候选直接放弃。
4. 让位**同侧优先**：绕弦旋转的候选里，弯折侧向不变者优先；只有同侧压不住且穿透超过 E18 验收阈值（`CLIP_CAP` = 20mm）才允许翻面。取舍写在明处：反关节的解剖错误，代价远大于几厘米的可见穿透。
5. 可诊断性：`__app.pushDiag()` 暴露逐阶段量（off0 / offPush / offRevert / offTilt + 推出量）；E7 的违例信息带上诊断 —— 出问题先量是哪一步翻的，不再猜。
6. 顺带：`chainBendOff` 与 E7 同量纲（弯折点相对弦线在身体前向的投影），运行时与验收判的是同一个量。

- 验收：E7 违例 5 → 0（阈值未动：弯折 15mm / 伸直 30mm）；E18 网格真值 0.0mm、运行时采样 15mm（阈值 20mm）；E5/E6 平滑与连续性不回退
