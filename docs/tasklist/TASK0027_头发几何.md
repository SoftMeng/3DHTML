# TASK0027 头发几何：开放圆筒 → 旋转体发缕

- 状态：已完成 · 2026-11-25
- 产出：`index.html`（`buildLongHair`）

1. 症状：后发与鬓发用**开放圆筒**（`CylinderGeometry(..., openEnded=true)`）建模，背面被剔除 → 从正面看是一张能看穿的平板，呈现条纹状「面纱」。
2. 改法：改用**旋转体（LatheGeometry）**发缕 —— 剖面从头顶沿脑后收到腰际、末端收尖，闭合且贴头骨；材质加 `DoubleSide` 兜底。
3. 剪影不变：后发起点/长度/扁率（1.28/1/0.52）与两鬓位置、长度保持原值，毛线帽球冠与兜帽不动；mesh 数不变（头发 2 + 兜帽 1），不抬 draw call。
4. 摆动仍只驱动 `hairSwing` 组（静态帽壳与兜帽刚性跟随头骨）。
